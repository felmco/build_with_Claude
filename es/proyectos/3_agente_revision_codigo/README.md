# 3 Agente Revision Codigo

Desarrolla un agente que revisa PRs de código y sugiere mejoras.

## Configuración
1. Instala las dependencias: `pip install -r requirements.txt`
2. Define `ANTHROPIC_API_KEY` en un archivo `.env`
3. Ejecuta `python main.py` (esqueleto de partida: implementa tu lógica en `main()`)
