# Construir con Claude: Curso de Formación Integral

¡Bienvenido al curso de formación integral **Construir con Claude**! Este curso te llevará desde un nivel principiante hasta avanzado en la creación de aplicaciones con la API de Claude usando Python.

## 🎯 Visión General del Curso

Este programa de formación está diseñado para desarrolladores que desean dominar la creación de aplicaciones impulsadas por IA utilizando la API Claude de Anthropic. Ya seas un principiante que acaba de empezar o un desarrollador experimentado que busca profundizar sus conocimientos, este curso tiene algo para todos.

### Lo Que Aprenderás
- 🚀 Empezar con la API de Claude y el SDK de Python
- 💬 Construir aplicaciones de IA conversacional
- 🛠️ Implementar el uso de herramientas (tool use) y llamadas a funciones
- 📊 Optimizar costes con el almacenamiento en caché de prompts (prompt caching)
- 🤖 Crear agentes autónomos
- 🔍 Construir sistemas RAG (Generación Aumentada por Recuperación)
- 🎨 Trabajar con visión y capacidades multimodales
- 📈 Optimizar el rendimiento y los costes
- 🏭 Desplegar aplicaciones listas para producción

## 🛠️ Instrucciones de Configuración

### 1. Clonar o Descargar los Materiales del Curso
```bash
cd build_with_Claude
```

### 2. Configurar el Entorno de Python
```bash
# Crear entorno virtual
python -m venv venv

# Activar entorno virtual
# En macOS/Linux:
source venv/bin/activate
# En Windows:
venv\Scripts\activate

# Instalar dependencias
pip install anthropic python-dotenv
```

### 3. Configurar la Clave API
```bash
# Crear archivo .env
echo "ANTHROPIC_API_KEY=tu-clave-api-aqui" > .env
```

### 4. Probar tu Configuración
```bash
python -c "import anthropic; print('¡Configuración exitosa!')"
```
