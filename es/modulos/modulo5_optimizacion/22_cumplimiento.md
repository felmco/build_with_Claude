# 5.6 Cumplimiento y Privacidad de Datos

## Política de Datos de Anthropic
- **API Estándar:** Por defecto los datos no se usan para entrenamiento (revisa los términos comerciales más recientes).
- **Retención:** Las entradas y salidas se conservan durante un periodo limitado (30 días al momento de escribir esto); la retención cero de datos está disponible por acuerdo. Verifica los términos vigentes para tu organización, y ten en cuenta que Bedrock, Vertex y Foundry siguen las políticas del proveedor de nube.

## GDPR / CCPA
Si un usuario pide ser borrado, debes borrar sus datos de tus registros.
- Claude no almacena datos de usuario a largo plazo, pero *tú* sí (en logs/DB).
