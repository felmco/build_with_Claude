# Hands-On Exercises

This directory contains practical exercises to reinforce your learning at every level.

## 📋 Exercise Structure

Each exercise includes:
- **Objective**: What you'll build
- **Difficulty**: Beginner / Intermediate / Advanced
- **Prerequisites**: Required knowledge
- **Instructions**: Step-by-step guide
- **Solution**: Reference implementation
- **Extensions**: Ideas to expand the exercise

## 🎯 Beginner Exercises

### [Exercise 1: Hello Claude](./beginner/01_hello_claude.md)
**Time**: 15 minutes
- Make your first API call
- Handle responses
- Print formatted output

### [Exercise 2: Simple Chatbot](./beginner/02_simple_chatbot.md)
**Time**: 20 minutes
- Build an interactive input loop
- Send each message to Claude
- Exit cleanly

### [Exercise 3: Text Generation & Summarization](./beginner/03_text_generation.md)
**Time**: 20 minutes
- Summarize and rewrite text
- Adjust tone
- Extract key points

### [Exercise 4: Context-based Q&A](./beginner/04_qa_system.md)
**Time**: 25 minutes
- Inject context into a prompt
- Ground answers in the provided text
- Handle questions the context cannot answer

### [Exercise 5: Temperature Experiments](./beginner/05_temperature_experiments.md)
**Time**: 15 minutes
- Test different temperature settings (on Haiku 4.5)
- Compare responses
- Learn which models still accept sampling parameters

## 🔧 Intermediate Exercises

### [Exercise 6: Streaming Chatbot](./intermediate/01_streaming_chatbot.md)
**Time**: 45 minutes
- Implement streaming responses
- Manage conversation history
- Handle interruptions

### [Exercise 7: Image Analysis Tool](./intermediate/02_image_analysis_tool.md)
**Time**: 30 minutes
- Process image files
- Extract information
- Generate descriptions

### [Exercise 8: Basic Tool Use](./intermediate/03_tool_use_implementation.md)
**Time**: 40 minutes
- Define a calculator tool
- Handle tool calls
- Return results to Claude

### [Exercise 9: Conversation Management](./intermediate/04_conversation_management.md)
**Time**: 30 minutes
- Maintain a message history
- Add a system prompt
- Handle long conversations

### [Exercise 10: Multi-turn Logic](./intermediate/05_multi_turn_interactions.md)
**Time**: 45 minutes
- Build a "20 Questions" game
- Enforce rules with a system prompt
- Track state across turns

## 🚀 Advanced Exercises

### [Exercise 11: RAG System](./advanced/01_rag_system.md)
**Time**: 2-3 hours

- Implement retrieval

### [Exercise 12: Autonomous Research Agent](./advanced/02_autonomous_agent.md)

- Integrate the web search tool

### [Exercise 13: Batch API Processing](./advanced/03_batch_processing.md)

- Handle results asynchronously
- Implement error recovery

## 📝 How to Use These Exercises

### Step 1: Read the Exercise
- Understand the objective
- Review prerequisites
- Check difficulty level

### Step 2: Try It Yourself
- Attempt the exercise independently
- Refer to course modules if needed
- Don't look at solutions immediately

### Step 3: Compare with Solution
- Check your implementation
- Learn from differences
- Understand alternative approaches

### Step 4: Extend It
- Try the extension ideas
- Add your own features
- Share your implementations

## 💡 Tips for Success

1. **Start Simple**: Begin with beginner exercises
2. **Code Along**: Type the code yourself
3. **Experiment**: Modify examples to see what happens
4. **Debug**: Practice troubleshooting errors
5. **Document**: Add comments to explain your code
6. **Share**: Show your solutions to others
